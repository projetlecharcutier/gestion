# Jeu de Mémoire

Un petit jeu de mémoire (memory game) jouable directement dans un navigateur, sans aucune dépendance.

## Comment jouer

1. Ouvrez le fichier `index.html` dans un navigateur récent (Chrome, Firefox, Edge, Safari).
2. Cliquez sur deux cartes pour les retourner.
3. Retrouvez les 8 paires de symboles identiques.
4. Le compteur de coups et le chronomètre s'affichent en haut.

Cliquez sur **Recommencer** pour lancer une nouvelle partie.

## Fichiers

- `index.html` — structure de la page
- `style.css` — mise en page et animation des cartes (effet de retournement 3D)
- `script.js` — logique du jeu (mélange, retournement, paires, chrono)

## Technologies

HTML, CSS et JavaScript natifs (vanilla). Aucune build, aucun paquet, aucune dépendance externe.
